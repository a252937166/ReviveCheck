## One-sentence project overview (required)

> ReviveCheck is release attestation middleware for Portaldot V3: a registry contract that other contracts read through a guard library, evidence stored on-chain through the native Remark module, and a verification API (MCP, REST, JS, CLI) that checks releases through both V3 interfaces.

Middleware: ReleaseRegistry 0xe949b200edf070b9d425b206ed24dc8fe5b7d339 (block 162962) plus the ReviveCheckGuard Solidity library and its reference consumer VerifiedTokenList 0xd0bd833b4b8658b1230a0e9a99640935b3c65819 (block 164220); pUSD listed on an approved release in block 164313, read back through EVM RPC and ReviveApi. API: 12 read-only tools over MCP, REST, JavaScript and CLI; writes are dry-run and signed in the user's wallet. Public site opening into an app: registry dashboard with live lookups, a lifecycle studio (Polkadot/EVM wallets), docs and a reviewer. One full run through the studio UI signed submit, approve and remark on-chain. 115 automated tests pass, including the compiled contracts in an in-memory EVM.
